# ADR-0006：本地优先、默认不出网

| 项 | 内容 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-03 |
| 决策者 | 项目维护者 |
| 影响的模块 | `server/index.mjs`、`server/store.mjs`、`agent/provider.mjs`、`agent/loop.mjs`、`agent/mcp-server.mjs`、`desktop/main.mjs`、`web/views.js`、`tools/check-web.mjs`、`data/config.json` |

## 背景

服务的默认监听地址是 `HOST = process.env.QXG_HOST || argOf('host', '127.0.0.1')`，端口默认 19730。也就是说，开箱状态的问心卦只接受本机回环连接，不向局域网暴露，也没有任何「注册」「登录」「同步」入口。

`data/config.json` 里的默认配置中，`agent.enabled` 是 `false`：

```json
"agent": { "enabled": false, "provider": "deepseek", "baseUrl": "", "apiKey": "",
           "model": "", "temperature": 0.6, "maxTokens": 0, "maxRounds": 6, "useNativeTools": true }
```

`agent/provider.mjs` 的四类预设是 DeepSeek（`https://api.deepseek.com/v1`）、OpenAI（`https://api.openai.com/v1`）、本地 Ollama（`http://127.0.0.1:11434/v1`，`needsKey: false`，注明「完全离线」）、自定义（任一 OpenAI 兼容端点）。`resolveConfig()` 会算出 `isLocal`：

```js
isLocal: /127\.0\.0\.1|localhost|0\.0\.0\.0/.test(baseUrl),
```

界面上「AI 助手」页在未配置时只显示配置表单。README 明确写着：「AI 助手需要你自己提供模型 Key 或本地模型。程序本身不带模型，**没有 Key 时助手页只显示配置表单**，其余功能全部可用。」

Key 的存放与使用有一条明确的边界：`apiKey` 以明文存在本机 `data/config.json`，`server/index.mjs` 侧对外**绝不回显原文**——`maskAgent()` 返回 `apiKey: undefined` 与 `apiKeySet: !!cfg.apiKey`，只在用户明确传入非空 `apiKey` 时才改写（传空串表示清除）。README 与 `server/store.mjs` 的 `DEFAULT_CONFIG` 注释都提醒：别把 `data/` 提交到公开仓库，也别放同步盘。

其余功能一律本机完成：起卦、断语、校勘、走势、复盘、导出、插件都不触网；卦典与爻辞来自随包的 `knowledge/*.json`。构建期要下载 Electron 与打包工具时走镜像（`ELECTRON_MIRROR` 等），那是开发机的事，与用户运行时无关。

## 决策

问心卦**必须**是本地优先的单机程序：**不得**要求账号，**不得**内建云同步，**不得**把卦录或配置发往任何第三方。默认监听**必须**是本机回环地址，改变监听范围**必须**由用户显式指定。唯一的出网路径**必须**是「用户显式启用并配置 AI 助手（或外部 agent 经 MCP 调用同一套工具）」；未启用时程序**不得**发起任何外部网络请求。API Key**可以**以明文存在本机 `data/config.json`，但对外接口**不得**回显原文；数据目录**不得**被程序自行上传或同步。

## 理由

1. **数据是私事。** 卦录记录的是求职、债务、健康、情感这类内容，且带精确到分钟的时间与地点。这类数据的默认归宿只有一处——用户自己的磁盘。
2. **无账号即无信任成本。** 不需要注册就意味着不需要邮箱、不需要密码、不需要服务端，也就没有「服务下线后数据取不回来」的风险。这与 [ADR-0002](./ADR-0002-一卦一个JSON文件.md) 的耐久目标一致。
3. **离线可用是长期可用的前提。** 断语是规则引擎（[ADR-0003](./ADR-0003-断语用规则引擎.md)），卦典随包，历法自算，因此没有网络时程序的核心功能一个都不少。把 AI 助手做成可选增强而不是必需组件，正是为了保住这一点。
4. **出网范围越小，事故面越小。** 唯一的外发路径被压缩到「一次 `fetch` 到用户填的 `baseUrl`」，连 SDK 都没有（`agent/provider.mjs` 只用 `fetch` 与 `AbortController`），因此这条路径的审计成本很低：看 `PROVIDERS` 与 `resolveConfig()` 就够了。
5. **本地模型是真正的一条出路。** Ollama 预设的 `needsKey: false` 让「既要用 agent 又完全不出网」成为可能，这是本决策能长期成立的现实支撑。

## 后果

### 正面

- 隐私边界清晰：不出网是默认状态，出网是用户动作的结果。
- 断网、内网、无管理员权限的机器上都能用；`%APPDATA%\问心卦\data` 与程序分离，卸载不删数据。
- 与其他「本地优先」的形态可组合：`问心卦(桌面窗口).vbs` 用系统 Edge 以 `--app` 模式开独立窗口，同样不需要联网。
- 密钥不落日志、不回显，界面上只能看到「已设置」与否。
- 可被外部 agent 通过 MCP 驱动（[ADR-0009](./ADR-0009-MCP接入面.md)），而 MCP 服务本身是 stdio 子进程，不额外开网络端口。

### 负面

- **能力受本地算力限制。** 不接云模型时，助手只能用本地小模型，工具调用常需走文本协议降级（`extractTextToolCalls()` 从 ```json {"tool":…} ``` 里抠），能力弱于云模型。这是刻意接受的代价。
- **密钥以明文落盘。** 这是本 ADR 最明确的一处妥协：任何能读到 `data/config.json` 的进程都能拿到 Key。缓解措施只有三条——`data/` 不进公开仓库、不放同步盘、接口不回显。
- **没有多端同步。** 换机器要手工复制 `data/` 或导出整包备份再用 `POST /api/restore` 恢复。移动端「接口齐了但没做」，也受此约束。
- **单机单用户。** 没有并发与权限模型；`Store` 的写盘没有跨进程锁，两个进程同时写同一条记录会互相覆盖。
- **默认地址可被环境变量覆盖。** `QXG_HOST` 与 `--host` 允许监听非回环地址，此时没有任何认证层——把它暴露到网络上就等于把卦录交出去。程序不做提示，靠使用者理解这条边界。

## 备选方案与为何不选

| 方案 | 为什么没选 |
|---|---|
| 云端账号 + 同步 | 与「数据是你自己的纯文本」这一立项表述直接冲突，且引入服务端运维、账号体系与数据泄露面。 |
| 用系统钥匙串（DPAPI／Keychain）存 API Key | 需要平台相关代码或第三方库；零依赖前提下要自己写平台分支与封装，收益只是把明文换成密文，而 `data/` 本身已经是用户私有的本地目录。当前选择是把风险写在文档里，而不是加一层维护成本。 |
| 默认接一个「免费网关」让用户开箱即用 | 会让每一条助手对话都经过第三方，且服务可用性不受本项目控制；与「无 Key 时其余功能全部可用」的现状相比，收益不足以抵消隐私与依赖代价。 |
| 把模型下载随包分发 | 体积从几十 MB 涨到 GB 级，且模型许可与升级要长期维护；用户自行安装 Ollama 更干净。 |
| 用命令行参数而非配置文件存 Key | 会进命令历史与进程列表，泄露面更大；也更容易被误截图。 |
